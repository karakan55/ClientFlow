# ClientFlow

Modern ve kullanımı kolay bir online randevu yönetim sistemi.

ClientFlow; güzellik merkezleri, kuaförler ve benzeri işletmeler için müşterilerin online olarak randevu oluşturmasını ve işletmenin randevuları yönetmesini sağlayan bir web uygulamasıdır.

## Özellikler

- Online randevu oluşturma
- Hizmet seçimi
- Personel seçimi
- Tarih ve saat seçimi
- Hizmet süresine göre müsait saat hesaplama
- Dolu saatlerin otomatik engellenmesi
- Aynı personelde çakışan randevuların engellenmesi
- Çalışma saatleri kontrolü
- Randevu başarı ekranı
- WhatsApp bağlantısı
- Admin paneli
- Admin giriş sistemi
- Randevuları görüntüleme
- Randevu iptal etme
- İptal edilen saatlerin tekrar müsait olması
- Randevuların JSON dosyasında saklanması

## Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript
- Node.js
- HTTP Server
- JSON
- Git / GitHub
